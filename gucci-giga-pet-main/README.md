## Gucci Giga Pet
## Project 2 – Giga Pet JavaScript

Gucci Giga Pet is an interactive virtual pet game featuring my French Bulldog, Gucci. This project was created using HTML, CSS, JavaScript, and jQuery for COMP 484 Web Engineering.

## Live Website

**https://jamiecasino.github.io/gucci-giga-pet/**

## Features
- **Treat:** Increases Gucci's weight and happiness.
- **Play:** Increases happiness while decreasing weight.
- **Exercise:** Decreases weight and happiness.
- **Sleep:** Allows Gucci to rest and recover.
- **Default:** Returns Gucci to his original picture.
- **Interactive Photos:** Gucci's picture changes depending on the selected action.
- **Sound Effects:** Plays sounds during interactions.
- **Animations:** Displays visual effects and animated reactions.
- **Pet Statistics:** Updates Gucci's information dynamically.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- jQuery

## How to Play
Click the action buttons to interact with Gucci. Watch his picture, statistics, and reactions change based on the selected activity.
